# StudyFlow

Plataforma de estudos gamificada em Flask.

## Conteúdo desta versão

- Videoaulas do YouTube incorporadas diretamente na página de cada aula.
- Flashcards interativos dentro das aulas.
- Perguntas e respostas para Matemática, Física, Química, Português, História e Biologia.
- Questões de Matemática com contas e problemas de aplicação.
- Conteúdo organizado em módulos por nível de dificuldade.
- XP, progresso, conquistas, streak, metas, ranking, estatísticas e cronômetro.
- Apenas 4 arquivos Python e sem Blueprint.

## Executar

```bash
pip install -r requirements.txt
python run.py
```

Depois, abra o endereço mostrado pelo Flask no navegador.
